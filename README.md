# Claude-Code-Web-App-Practise

This is my first project using Claude Code* - I am actually using Ollama (an open source AI model) and gemma4 (a open source LLM) using Claude Code's interface.

This means, I get to learn how to use Claude Code for free, running completely locally on my computer with 100% privacy.

For this simple practise I will be making a simple, but professional, business website using HTML and CSS.
